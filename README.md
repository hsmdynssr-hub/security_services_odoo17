# Security Services Management - Odoo 17

## Overview

**Security Services Management** is a custom Odoo 17 module designed for managing security service operations, contracts, operators, and field activities.

The module helps security companies organize operational workflows, improve service tracking, and manage customer contracts efficiently inside Odoo.

This solution is suitable for:

* Security service companies
* Facility management businesses
* Guard operations management
* Contract-based service providers
* Multi-site security operations

---

# Main Objectives

The project was developed to solve common operational problems in security service businesses such as:

* Manual contract tracking
* Difficulty managing security operators
* Weak operational monitoring
* Lack of centralized customer management
* Poor reporting and workflow organization

The module centralizes all operations inside Odoo ERP.

# Installation

## 1. Copy module to custom addons path

```bash
custom_addons/security_services_odoo17
```

## 2. Restart Odoo Server

```bash
python odoo-bin -u security_services_odoo17
```

## 3. Install Module

* Activate Developer Mode
* Update Apps List
* Install the module
